How to read this dashboard
Investment priority matrixRight = more frequent, up = more severe. Dashed lines are the medians. Red / Invest now = top-right and priority score ≥ 60. Orange = targeted upgrade, yellow = process fix, green = monitor.
Priority score (0–100)30% frequency + 35% severity + 20% open actions + 15% repeat rate, each scaled against the highest risk family.
Severity indexLTI = 5, MTI = 3, commuting/contractor = 2, FAI = 1, near miss = 0.5, plus 0.5 per lost day. It weights outcomes, so one LTI counts more than several near misses.
CRCI – verified-effective closureShare of completed actions confirmed as effective on follow-up. High completion with low CRCI means actions are being closed without fixing the risk.
HIRADC bandsD1 = extreme, D1-C = high (critical), D2 = medium, D3 = low. "Initial" is before controls, "residual" is after controls.
Risk portfolio statusConfirmed = incident has happened. Emerging = 2+ findings, no incident yet. Monitor = 1 finding only. Grouped = events outside the top 12, summed. Data gap = incidents with no hazard event recorded; they can't be ranked until tagged.
Findings vs actionsA finding is one hazard report (one Finding ID). Each finding can have several corrective actions. Charts and the map count findings; open-action counts, completion % and the Hazard actions tab count actions.
Recurrence checkA "Repeat" tag only counts as validated if an earlier record exists for the same area and hazard event. Commuting is excluded from plant recurrence and hotspot views.

Register drill-down

Hazard actions lists one row per corrective action; a finding with 3 actions appears 3 times, with the same Finding ID. Search looks in every column. Type several words to narrow down; each word must match the start of a word somewhere in the row, in any order (e.g. 2025 warehouse LTI). Month names work too (aug, august, q3).

Source: synthetic demo dataset — HIRADC register (760 assessed lines), incident register (105 dated records, 2019–2026) and hazard/observation tracker (183 action rows / 128 unique findings, 2026). All records, names, areas and the site map are fictional. Priority score = 0.30 × frequency + 0.35 × severity index (injury-class weight + 0.5 × lost days) + 0.20 × open actions + 0.15 × repeat-incident rate, each normalised to the highest-scoring risk family. Quadrant thresholds are the medians for frequency and severity across the 10 risk families.

Data-quality notes (demo): 16 of 105 incidents (15.2%) carry no risk-family tag and are excluded from the family-level matrix, Pareto and category charts (they still count in the KPI strip). Only 217 of 760 HIRADC lines (28.6%) are cross-referenced to a risk family, so per-family HIRADC counts understate exposure — the register-wide 197-of-760 figure in the KPI strip is the reliable one. 8.9% of HIRADC lines have no residual rating.
